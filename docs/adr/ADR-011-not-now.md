# ADR-011: Not now (explicit non-goals)

## Status

Accepted

## Out of scope for v1

Kubernetes, microservices, multi-agent systems, voice/video, fine-tuned LLMs,
PyTorch/TensorFlow/BERT training, FAISS, Chroma, MongoDB, BM25/Elasticsearch,
org/team tenancy, document sharing, Terraform/AWS production, Neo4j numeric
mastery, per-user Qdrant collections, GitFlow.

## Revisit when

- S3 eval shows retrieval failure → discuss lexical search.
- Gemini Pro cost exceeds budget → discuss Flash for extract only.
- A second region or enterprise VPC is required → Terraform/AWS.
